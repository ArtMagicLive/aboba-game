# 🗿 Абоба: Разрушение

Нативная Android-игра на Kotlin: пиксельные солдатики прут на абоба-тотем, а ты их взрываешь.
Яркий мультяшный стиль, физика с разлётом, пять видов оружия, волны, боссы, магазин улучшений.

## Что внутри

**Оружие (5 штук):**
| # | Название | Как работает |
|---|----------|--------------|
| 0 | 💥 Взрыв | Бесплатный клик-взрыв, основной инструмент |
| 1 | ⚡ Молния | Бьёт с неба, урон по площади |
| 2 | ☄ Метеор | Падает с неба, большой взрыв |
| 3 | 🕳 Чёрная дыра | Затягивает и медленно убивает |
| 4 | ☢ Ядерка | Три огромных взрыва + вспышка |

**Солдатики:**
- Обычный — 1 HP
- Толстый — 4 HP, медленный
- Быстрый — 1 HP, носится
- Зомби — 3 HP
- БОСС — 22 HP, каждые 5 волн, с полоской здоровья

**Механики:**
- Волны с растущей сложностью, боссы каждые 5 волн
- Комбо-множитель за серию убийств
- Абоба-тотем с 5 жизнями — если солдатик дошёл, −1 жизнь
- Монеты за убийства, магазин с 4 улучшениями (по 8 уровней)
- Рекорды и прогресс сохраняются в SharedPreferences
- Синтезированный звук (генерируется кодом, без бинарных ресурсов)
- Тряска экрана, вспышки, обломки, паника солдатиков и кричалки «абоба», «ва!», «67»

## Как собрать APK

1. Установи **Android Studio** (Ladybug или новее).
2. `File → Open` → выбери папку проекта.
3. Дождись Gradle Sync (студия сама подтянет Gradle 8.7 и AGP 8.5.2).
4. Подключи телефон по USB с включённой отладкой **или** создай эмулятор.
5. Нажми **Run ▶** — приложение установится на устройство.

Либо собрать APK вручную:

```bash
# из корня проекта
./gradlew assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk
```

На Windows: `gradlew.bat assembleDebug`

## Требования

- Android 8.0 (API 26) и выше
- JDK 17
- Android Studio с Android SDK 34

## Структура

```
app/src/main/java/com/aboba/destruction/
├── MainActivity.kt          — точка входа, Activity
├── Prefs.kt                 — SharedPreferences: монеты, рекорды, улучшения
├── audio/
│   └── SoundFx.kt           — синтез WAV + SoundPool
└── game/
    ├── GameView.kt          — SurfaceView + игровой поток
    ├── Entities.kt          — типы солдатиков, частицы, эффекты
    └── GameWorld.kt         — вся логика и отрисовка (главный файл)
```
